# История версий

## 1.2.1

- Лицензия MIT в репозитории, Cargo metadata и `.yap`.
- Собственный совместимый с YAM индекс для установки пакета по имени.
- Требование `arch.aarch64` в manifest без ограничения по модели колонки.
- Повторная упаковка одного бинарника даёт одинаковый архив.

## 1.2.0 — первая публичная интеграционная версия

- JSON API v1 через `--json`, стабильные коды ошибок и `--request-id`.
- `switch <имя>`: применить новый выбор и сохранить его после успеха.
- Защита CLI от одновременных изменений; атомарная запись конфига.
- Все диагностические сообщения применения перенесены в stderr.
- Переносимая кросс-сборка, пакет YAM, примеры интеграции и CI.

## 1.1.0 — рабочий прототип

- Подмена всех кэшированных моделей `activation/alisa` с сохранением CRC32.
- Отключение повторной проверки активации и восстановление при возврате на Алису.
- Подтверждены голосовой ответ на «Ясмина» и работа после перезапуска Mini 2.
