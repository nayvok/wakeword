# Roadmap

## Первая публичная версия — готово

- Переключение `alisa` / `yandex` / `yasmina`; проверено на Мини 2 с часами.
- Бэкапы, проверка CRC32 и возврат к оригиналам.
- CLI, JSON API v1 и интеграция YAM.
- Инструкция, примеры клиентов, тесты и CI.

## Следующие этапы

- Автоматическое восстановление подмены при новой версии серверной модели.
- Проверка других моделей Станций и интеграции BetterYAM.
- Проверяемый импорт готовых пользовательских моделей.
- Исследование совместимого обучения слова по тексту («компьютер» и т. п.).

Регистрация строки имени не обучает нейросеть. Legacy-команды `add`/`remove`
сохранены для прежних экспериментов; стабильный пользовательский процесс
добавления своих слов пока не заявлен. Сроки следующих этапов не определены.
